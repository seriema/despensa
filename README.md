# Despensa

A household stock app: keep two months of food and household supplies at home, count once a month,
and refill from the supermarket in one order – with price tracking to spot when the store raises prices.

- **Status:** prototype (web app, installable on Android via "Add to Home screen"). Data stays on the device.
- **Store support:** Rede Krill (Litoral Norte, SP). See `docs/KRILL_API.md`.
- **For contributors / agents:** start with `PLAN.md` and `CLAUDE.md`.

```bash
cd app && npm install && npm run dev     # local dev
npm run build                            # single-file build in app/dist
```
