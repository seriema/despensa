# Store comparison research (2026-11-17)

Question: is supporting other stores than Rede Krill worth it (incl. transport)?
Google Sheet: "Despensa – store price comparison (Nov 2026)" (kept privately by the author).

| Store | Matched / 65 | Basket vs Krill | Transport |
|---|---|---|---|
| Extra Mercado (online, default store) | 61 | −1.2 % | local store in Boiçucanga; local prices need login |
| Tenda Atacado Bertioga | 64 | −11 to −13 % (produce −25 %) | free pickup, ~115 km round trip ≈ R$65–100; delivery from R$34.71, earliest slot 5+ weeks out |
| Mercadão Atacadista Bertioga | 27 (flyer only) | −24 % on flyer items | no online shop/delivery |

Conclusion: not worth building multi-store now. Tenda only if replacing most of the monthly shop and
combining with a Bertioga trip (≈ R$30–60/month estimated saving). Extra Boiçucanga could later be watched for promos.
Automation: Tenda has structured data (Next.js + API with branch), Extra has a JSON search API but store choice needs login,
Mercadão only flyer images. Files: comparison_filled.csv, stores.csv, krill_price_history.csv.
